# Polski practice bot

A Telegram bot that drills Polish grammar topics from your language course. Pick a topic, get an endless
stream of gap-fill tasks generated by an OpenAI model, answer in the chat, and get a Russian explanation
when you slip. Runs on Cloudflare Workers (free plan) with one Durable Object per chat.

Design document (Russian): `docs/superpowers/specs/2026-09-11-polish-practice-bot-design.md`.

## How it works in one paragraph

Topics are markdown files in `topics/`. A build step validates them and bundles them into
`src/topics.generated.json`. The Worker receives Telegram webhooks, answers `200` immediately and runs the
exercise cycle in the background: it grades exact-match answers locally, otherwise asks the model to check,
and in parallel asks the model for the next task. Verdict, explanation and the next task arrive as one
message. Session state lives in a Durable Object keyed by chat id and expires after a day of inactivity.

## Prerequisites

- Node 24+ and npm.
- A Cloudflare account (free plan is enough) and `npx wrangler login`.
- A Telegram bot token from **@BotFather**.
- An OpenAI API key created in a **separate project** on platform.openai.com, with a **hard monthly spend
  limit** set in that project's billing settings. The key needs only the Responses API.

## Setup

1. Install dependencies: `npm install`.
2. Pick a model that supports strict Structured Outputs and (ideally) a reasoning effort setting. Put its id
   in `wrangler.toml` under `[vars] OPENAI_MODEL`. If the model has no reasoning control, set
   `OPENAI_REASONING_EFFORT = "none"`; otherwise keep `"minimal"` — reasoning tokens are billed as output.
3. Choose the per-chat daily cap in `DAILY_LIMIT_PER_CHAT` (default 150). It protects your OpenAI budget
   from a runaway chat; pick a value a real session never hits.
4. Create secrets:
   ```bash
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put OPENAI_API_KEY
   npx wrangler secret put TELEGRAM_WEBHOOK_SECRET   # any random string, e.g. `openssl rand -hex 24`
   ```
5. First deploy: `npm run deploy`. The Durable Object migration in `wrangler.toml` uses
   `new_sqlite_classes` — the only storage backend available on the free plan; `new_classes` would fail.
6. Register the webhook and the command menu:
   ```bash
   TELEGRAM_BOT_TOKEN=… TELEGRAM_WEBHOOK_SECRET=… npm run webhook -- https://polski-bot.<your-subdomain>.workers.dev
   ```
   This sets `allowed_updates` to `message` and `callback_query` only; edited messages are never delivered.
7. Open the bot in Telegram, press Start, pick a topic.

### Continuous deployment

`.github/workflows/ci.yml` runs lint, type check, tests and the topic bundle on every push, and deploys on
`main`. Add `CLOUDFLARE_API_TOKEN` (Workers Scripts: Edit; Durable Objects: Edit) and `CLOUDFLARE_ACCOUNT_ID`
as repository secrets.

## Adding a topic

Adding a topic is adding a file and pushing. No code changes.

1. Copy the structure of `topics/01-czas-przeszly.md`. Frontmatter has exactly two fields: `id`
   (`^[a-z0-9-]{1,32}$`, unique) and `title` (button caption, up to 64 characters).
2. Required sections: `## Описание`, `## Генерация`, `## Проверка`. Optional: `## Вариативность`,
   `## Типичные ошибки`, `## Примеры`. Everything is prose for the model, in Russian.
3. The usual workflow is to hand your lesson notes to an assistant and ask for a topic file in this format,
   then read it through, drop it into `topics/` and push. Two rules for `## Вариативность` axes:
   - One axis is the trained contrast, listed by **Polish** categories, exhaustively (e.g. masculine-personal
     vs non-masculine-personal plural, not "gender × number"). Other axes are flavour: five to ten values,
     not hundreds.
   - The task must express the target cell on its own: the Polish subject must make the required form
     unambiguous.
4. Fill `## Типичные ошибки` right after the lesson — what the group actually got wrong is the most valuable
   line in the file and the first thing forgotten. Two or three pairs in `## Примеры` set the difficulty;
   there is no level field on purpose.
5. Run `npm run topics` locally; a broken file fails the build with a one-line reason, and CI does the same.

Removing or renaming a topic breaks live sessions on that topic; the bot tells the learner the topic was
removed and shows the list. That is expected.

## Manual quality pass

Before trusting a new topic, run it through the real model (costs a few cents):

```bash
npm run topics
OPENAI_API_KEY=… OPENAI_MODEL=… npm run quality -- <topic-id>
```

It prints three tasks and the model's verdicts on planted answers. Read the checking verdicts as carefully as
the tasks: the checking prompt is the only part of a new topic that reaches learners without a human look.

## Commands

`/topics` (also `/start`), `/repeat`, `/why`, `/skip`, `/stop`, `/help`. The learner-facing texts are in
`src/strings.ts`.

## Operations

- Logs: `npx wrangler tail`. Tokens, keys and the webhook secret never appear in logs.
- Rotate a secret: `npx wrangler secret put <NAME>` with the new value, then (for the webhook secret) re-run
  the webhook script; for the Telegram token also revoke the old one in @BotFather; for the OpenAI key delete
  the old key in the project.
- Privacy: task texts and learner answers are sent to OpenAI. `/help` says so.
- Keyboard: `/help` recommends installing a Polish layout; a missing diacritic is noted, and counts as a
  mistake only when it changes the trained form.

## Troubleshooting

| Symptom | Check |
|---|---|
| Bot is silent | `curl https://api.telegram.org/bot<token>/getWebhookInfo` — url set, `last_error_message` empty? Secret matches `TELEGRAM_WEBHOOK_SECRET`? |
| "Лимит упражнений на сегодня исчерпан" | Per-chat daily cap (`DAILY_LIMIT_PER_CHAT`), resets at 00:00 UTC |
| "Лимит расходов OpenAI исчерпан" | The OpenAI project hit its hard spend limit or has no balance |
| "Бот сломан, нужна починка" | Permanent model error: wrong key, unknown model, rejected schema — see `wrangler tail` |
| "Секунду, ещё думаю" for more than a minute | A cycle died mid-way; the lease expires after 40 s and the next message recovers |

## Development

```bash
npm run check   # topics → types → lint → typecheck → tests
npm run dev     # local Worker with .dev.vars (copy .dev.vars.example)
```

Code, comments and docs are in English; topic files, prompts and everything the learner reads are in Russian.
