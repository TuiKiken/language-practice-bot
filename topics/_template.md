## Description
Что тренирует тема, одним абзацем: какая форма и какой выбор.

Сама грамматика, полностью — модель знает только то, что здесь написано:
- когда нужна форма, с примером: Mam nowego kota.
- окончания по родам/лицам, с примером на каждое;
- исключения, которые встречаются в заданиях.

Чего ещё не проходили и что не используется: множественное число, беглая
гласная, ...

## Generation
Дай простое польское предложение с одним пропуском; в скобках после
пропуска — подсказка в словарной форме: «Mam ___ (nowy / kot).» Ответ —
… слов(а): nowego kota. Не подсказывай нужную форму в задании.

Ось «…» решает …: перечисли для каждого значения конструкции и лексику.

Предложение должно однозначно задавать форму: если подходят два ответа,
такое задание не давай. Перечисли конструкции, которые запрещены
и почему (отрицание меняет падеж, глагол допускает оба падежа, …).

Меняй лексику и конструкции, не повторяй слова подряд.

## Checking
Главное — … Ошибку объясняй через …

Если форма верна, но ошибка в окончании, объясняй через …

Что засчитывать как верное с пометкой в note (допустимые варианты).
Проверяй все слова ответа; если верно только одно, скажи, какое.

## Axes
главная_ось: значение 1, значение 2, значение 3
вторая_ось: значение 1, значение 2

## Common mistakes
Заполнить после занятия — что группа на самом деле путала:
пишут … вместо …

## Examples
Mam ___ (nowy / kot). → nowego kota
Jestem ___ (dobry / lekarz). → dobrym lekarzem

## Rule
**Название** (вопрос?):
• когда — Пример.
• когда — Пример.

Окончания:
**род**: пример → пример
